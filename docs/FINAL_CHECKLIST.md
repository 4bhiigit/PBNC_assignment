## 2. Core Integrity & Security Checks (SPEC §22 & Assignment §9)

- [x] **No Fabricated Answers**: Answers are only parsed from the document (inline or answer key). If unstated $\rightarrow$ `not_found`; if conflicting $\rightarrow$ `conflict`.
- [x] **No Fabricated Benchmarks / Evidence**: All reports in `docs/demo_evidence/` were generated by running `scripts/evaluate.py` and `scripts/run_demo.py` against active code.
- [x] **Strict Tenant Isolation**: Foreign resource IDs return `HTTP 404 Not Found` (never 403) to prevent ID enumeration.
- [x] **No Secrets in Repo**: `.env` is gitignored; `.env.example` contains placeholders only; no hardcoded API keys or passwords.
- [x] **Magic-Byte Sniffing**: Non-PDF/image streams disguised with file extensions are rejected with `HTTP 400 Bad Request`.
- [x] **Decompression Bomb Protection**: Pillow `MAX_IMAGE_PIXELS` limit is enforced against high-dimension decompression attacks.
- [x] **Offline-First Functionality**: Pipeline executes end-to-end under `EXTRACTOR=rules` without external API dependencies.
- [x] **Prompt Injection Defense**: Untrusted document text is isolated in delimited blocks during LLM extraction and validated against strict Pydantic models.
